# To-Do List

A simple To-Do List web app built with HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using browser localStorage
- Responsive layout

## Technologies
- HTML5
- CSS3
- JavaScript

## Current Limitations
Task completion status and task deletion are not yet synchronized with localStorage. These features may be improved in future updates.

## About
This is my first web development learning project, created to practice HTML, CSS, JavaScript, DOM manipulation, and browser storage. AI assistance was used during learning and debugging.
